Temporal layer

Change over time, not one snapshot.

3 labelled frames in the same Haiku call. Code keeps the trend; only relative signals, no metres from a camera.

gap
subject ↔ target, in body-heights
loom
box area vs last tick (>1 = coming at you)
ordinal
closer / same / farther
touching
yes / no

Fires on a consistent trend for ≥ 3 ticks (or touching) · hysteresis + cooldown so it doesn't chatter.

Some hazards are about change, like a person getting closer to the water. For those triggers Haiku sees three frames labelled with their times, and returns boxes plus closer-or-farther. The code remembers the trend using only relative measures, like the gap in body-heights, and fires once it's consistent for three ticks.
